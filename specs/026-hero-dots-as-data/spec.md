# Spec 026: Горы hero как точки-данные

## Problem

Горы hero (spec 014) строятся сэмплингом JPEG сеткой с шагом `width / 176`.
Исходная картинка уже растрирована на решётку с шагом ~9.75 px. На ширине
1440 шаг сэмплинга 8.18 px, а решётка картинки даёт 8.4 px: близкие
несоизмеримые шаги дают муар, дальние хребты превращаются в шум,
градация размера точек теряется. Ошибка тона против исходника 0.074.

## Goal

Рисовать ровно те точки, что есть в исходной картинке. Каждая точка PNG
извлекается один раз как `(x, y, r, ink)` и хранится в репозитории как
данные. Модуль canvas масштабирует точки под секцию и анимирует их
текущей сборкой "снег на вершины". Ошибка тона не больше 0.03.

## Scope

- `design/hero-mountains/halftone-alpine-serenity-1672x941.png`: исходник
  1672x941, лежит вне `src/`, в сборку не попадает.
- `scripts/extract-hero-dots.mjs` и `pnpm run dots:extract`: детекция
  точек с учётом центральных точек ячеек, насыщенность `ink` (4 бита),
  квантование (x, y шаг 1/8 px, r шаг 1/16 px), сортировка по строкам
  решётки, детерминированный JSON, печать числа точек и tone MAE, выход с
  ошибкой при MAE > 0.03.
- `pngjs` в devDependencies (выпущен в 2023, проходит cooldown).
- `src/assets/images/landing/hero-dots.json`: сгенерированный ассет.
  `hero-mountains-halftone.jpg` удаляется.
- `src/scripts/hero-mountains.js`: fetch JSON и `buildField` вместо
  `loadImage` и `sampleField`. Cover по ширине, привязка к низу, минимум
  62% высоты, отсечение точек за краем, прореживание 2x2 только при шаге
  решётки ниже 4 CSS px. Skyline по колонкам шириной в
  один шаг со сглаживанием по соседям, depth и `snowcapTiming` как раньше.
  Крупные точки рисуются мельче (до 0.75 радиуса), мелкие не меняются.
  Осевшие точки кэшируются в offscreen-слой. Спрайты, alpha buckets,
  IntersectionObserver 0.5, reduced motion, resize и отложенное измерение
  скрытого лендинга не меняются.
- `deploy/cz/nginx.conf`: gzip для JSON, CSS, JS и SVG на origin.
- `tests/hero-mountains.test.mjs`: декодирование ассета, трансформация,
  skyline и depth, граница таймингов.
- `docs_dreamboard/project/frontend/frontend-docs.md` и
  `docs_dreamboard/project/devops/vercel-cd.md`.

## Out of scope

- Новая картинка, видео, анимированные форматы, SVG на каждую точку.
- Изменение текста, раскладки hero и остальных слайдов.
- Автоматическая установка nginx-конфига на `cz` (ставится вручную).

## Verification

- `pnpm run dots:extract` дважды даёт один и тот же файл, MAE <= 0.03.
- `pnpm run preflight` зелёный.
- Визуально 1440x900, 390x844, 844x390 при DPR 2-3 против исходника:
  дальние хребты серые и мягкие, нет муара, видна градация размера.
- Время кадра во время сборки 2.6 с не хуже старой реализации.
- PR: baseline-checks, guard, AI Review зелёные, треды закрыты.
